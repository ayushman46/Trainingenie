# TraininGenie SEO Growth Checklist

- [x] Canonical production origin configured as `https://www.trainingenie.com`.
- [x] Generated sitemap includes the existing indexable pages and excludes `/thank-you` and 404 routes.
- [x] Generated robots references `/sitemap.xml` and allows public pages.
- [x] Legacy routes permanently redirect to canonical pages.
- [x] Root metadata, Open Graph, Twitter cards, favicon, Apple icon, and branded image metadata configured.
- [x] Organization and WebSite JSON-LD configured with truthful company, contact, founder, and verified LinkedIn references.
- [x] Course JSON-LD configured for the individual course pages.
- [x] FAQPage JSON-LD matches the visible FAQ answers.
- [x] Breadcrumb navigation and BreadcrumbList JSON-LD added to deeper pages.
- [x] Utility pages have noindex handling.
- [x] Important SEO copy is server-rendered.
- [x] Internal links connect the homepage, pillars, courses, founder, clients, FAQs, and contact page.
- [x] Plus Jakarta Sans remains loaded through `next/font/google`.
- [x] Lint, TypeScript, and production build checks pass.

## Business owner must do

### Google Search Console

- [ ] Verify both `https://www.trainingenie.com` and the preferred property variant in Google Search Console.
- [ ] Submit `https://www.trainingenie.com/sitemap.xml`.
- [ ] Inspect and request indexing for the homepage.
- [ ] Inspect the main pillar pages and the individual course pages.
- [ ] Monitor Pages, Sitemaps, Core Web Vitals, Search results, Manual actions, and Security issues.

### Bing Webmaster Tools

- [ ] Verify the domain in Bing Webmaster Tools.
- [ ] Submit `https://www.trainingenie.com/sitemap.xml`.
- [ ] Review crawl errors and indexing status.

### Google Business Profile

- [ ] Create or claim a legitimate profile only where the business is eligible to operate.
- [ ] Use the exact company name, phone, website, and legitimate location information.
- [ ] Do not publish an address or service area that cannot be verified.
- [ ] Add real services, business photos, updates, and contact details.
- [ ] Ask real clients for honest Google reviews without incentives or fabricated wording.

### Authority and proof

- [ ] Publish approved client testimonials with name, role, organization, and permission.
- [ ] Add confirmed case studies without exposing confidential client details.
- [ ] Add trainer biographies and relevant credentials that can be verified.
- [ ] Add real training photos and delivery examples where permission exists.
- [ ] Ask legitimate clients and partners to link to the relevant TraininGenie page.
- [ ] Maintain consistent company and founder activity on the verified LinkedIn profiles.
- [ ] Add the business to relevant, legitimate training and learning directories.

### Content publishing

- [ ] Publish one genuinely useful article at a time, beginning with Excel, leadership, AI for finance, procurement tools, SAP DRC, and Design Thinking topics that match actual delivery capability.
- [ ] Give every article an original answer, author, date, references where needed, related training links, and a useful next step.
- [ ] Review Search Console queries monthly and improve pages based on real impressions and enquiries.
- [ ] Do not generate city-swapped pages, fake reviews, unsupported numbers, or thin keyword pages.

## External limitations

Search Console submission, Business Profile verification, reviews, backlinks, and ranking outcomes require account ownership or real-world activity. They were not claimed as completed by this repository change.
